# Диффузионные методы переноса стиля

Учебный проект по сравнению переноса художественного стиля через **IP-Adapter** и обучаемую **LoRA**. Композиция исходной фотографии фиксируется с помощью **ControlNet Canny**. На первом этапе воспроизведён baseline IP-Adapter + ControlNet; обучение и сравнение LoRA запланированы на второй этап.

## Этап 1: baseline

- Базовая модель: Stable Diffusion 1.5, разрешение 512 × 512.
- Стилевое условие: IP-Adapter SD 1.5; коэффициент 0.6.
- Структурное условие: ControlNet Canny; коэффициент 0.8.
- Генерация: DDIM, 30 шагов, CFG 7.5.
- Данные: WikiArt — 40 обучающих изображений одного стиля; COCO — 25 исходных фотографий (5 dev, 20 test).
- Для каждого фото: начальные шумы с seed `17`, `42`, `123`; всего **75 генераций**.
- Среда эксперимента: Google Colab, NVIDIA Tesla T4, Python 3.13.16.

### Результаты на тестовой выборке

| Показатель | Значение |
| --- | ---: |
| Фотографий / изображений | 20 / 60 |
| Edge F1 | 0.3749 (95% CI: 0.3083–0.4326) |
| DINO cosine | 0.3290 (95% CI: 0.2382–0.4201) |
| Среднее время генерации | 23.64 с на изображение |

Доверительные интервалы получены бутстрэпом по фотографиям (2000 повторений). Edge F1 характеризует совпадение контуров, DINO cosine — близость признаков изображения, **но ни одна из этих метрик сама по себе не оценивает художественный стиль**. Перенос стиля проанализирован отдельно на примерах. Автоматической числовой оценки стиля нет.

## Структура проекта

- `src/` — подготовка данных, генерация baseline, метрики и анализ;
- `configs/baseline.json` — зафиксированные настройки;
- `tests/` — автономные тесты;
- `scripts/train_lora.sh` — **планируемое** обучение LoRA (этап 2; не запускалось);
- `results/` — сводные метрики и выборочные примеры;
- `report/stage1_report.pdf` — отчёт первого этапа;
- `reproduce_results.ipynb` — проверка сохранённых результатов.

## Воспроизведение

Нужны Python 3.13, CUDA GPU (в эксперименте — Tesla T4) и интернет для моделей и данных. Рекомендуется Google Colab. Используйте предустановленные в Colab CUDA-версии `torch` и `torchvision`, затем:

```bash
python -m pip install -r requirements.txt
python -m src.prepare_data
python -m src.run_baseline --help
python -m src.evaluate --help
```

Сначала изучите `configs/baseline.json` и аргументы CLI. Для полного запуска сохраните скачанные изображения и начальные шумы; итоговые изображения и датасеты не следует коммитить целиком в Git из-за объёма и прав на распространение. В некоторых средах прямой HTTPS-доступ к `images.cocodataset.org` может завершаться ошибкой сертификата; не отключайте глобально проверку SSL. При необходимости используйте проверенное зеркало.

Исходный код и метрики опубликованы для проверки учебного эксперимента. Некоторые версии библиотек задаются допустимыми диапазонами, поэтому строго побитовое воспроизведение между разными средами не гарантируется.
